Where admins open this console. Used for links in alert and password reset emails.

The agent port, as firewalls see it from the internet. Forward this port straight to the server (it does its own TLS); it does not go through the reverse proxy in front of the console. Set it when the agent port has its own host name, for example because the console's name points at a proxy or CDN, or a different outside port because of NAT.

Advanced: the agent port is behind a TCP pass-through proxy or load balancer

Have the proxy send a PROXY protocol header so ComSense sees each firewall's real address. Headers are accepted only from these addresses. Leave empty when firewalls connect directly.

    fetch -o /tmp/comsense.pkg {% if agent_pin %}--no-verify-peer --no-verify-hostname {% endif %}{{ agent_url }}/downloads/{{ package.name }} && [ "$(sha256 -q /tmp/comsense.pkg)" = "{{ package.sha256 }}" ] && pkg-static add /tmp/comsense.pkg

    Or download it and copy it to the firewall yourself, then run pkg-static add {{ package.name }} there:

    Download {{ package.name }}
