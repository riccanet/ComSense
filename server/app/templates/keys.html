Enrollment keys

A firewall can only join this server by presenting a valid enrollment key. Paste the key into Services > PfManager Agent on the firewall after installing the package. Once enrolled, the firewall receives its own device token and the key is erased from the firewall.

Connecting a firewall

  1. Install the agent package from a shell on the firewall (Diagnostics > Command Prompt or SSH): {% if agent_packages %} 
    pkg-static add {{ public_url }}/downloads/{{ agent_packages[-1] }}
    {% else %} 
    pkg-static add https://<where you host it>/pfSense-pkg-PfManager-<version>.pkg
    Copy a built package into the server's downloads data folder to have it served from here. See docs/AGENT.md. {% endif %}
  2. Open Services > PfManager Agent, tick Enable, enter the server URL {{ public_url }} and the enrollment key, choose which remote actions to allow, and save.
  3. The firewall appears under Firewalls (after approval, if the key requires it).
