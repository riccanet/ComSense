Once enrolled, the firewall gets its own device token and the key is erased from it.

Connecting a firewall

  1. Install the agent package from a shell on the firewall (Diagnostics > Command Prompt or SSH): {% if package %} 
    fetch -o /tmp/comsense.pkg {% if agent_pin %}--no-verify-peer {% endif %}{{ agent_url }}/downloads/{{ package.name }} && [ "$(sha256 -q /tmp/comsense.pkg)" = "{{ package.sha256 }}" ] && pkg-static add /tmp/comsense.pkg
    The SHA-256 check guarantees the package is the one on this server{% if agent_pin %}, even though fetch cannot verify the self-issued certificate{% endif %}. {% else %} 
    pkg-static add https://<where you host it>/pfSense-pkg-ComSense-<version>.pkg
    Copy a built package into the server's downloads data folder to have it served from here with a ready-made install command. See docs/AGENT.md. {% endif %}
  2. Open Services > ComSense Agent, tick Enable, paste the enrollment code, choose which remote actions to allow, and save.
  3. The firewall appears under Firewalls (after approval, if the key requires it).
