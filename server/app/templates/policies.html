Manage firewall settings from one place

Policies will let you define settings once and keep every assigned firewall in line with them:

  • Aliases: shared host, network and port lists, such as your management addresses or block lists.
  • Firewall rules: standard allow and block rules placed at the top of each interface.
  • System settings: DNS servers, NTP, time zone, hostname and domain.
  • Packages: make sure the packages you rely on are installed everywhere.

Each firewall would report whether it is in sync, changes that cut a firewall off from ComSense would roll back automatically, and removing a policy would undo only what it created.

Until then ComSense only reads from firewalls: monitoring, alerts, update checks and configuration backups.

{% else %}
