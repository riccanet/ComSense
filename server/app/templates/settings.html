{% elif section == "/settings/addresses" %}

Addresses

{{ csrf() }}

Goes into new enrollment codes. Use it when firewalls reach the agent port under a different name or port than the console, such as a separate proxy host name or a NAT port. Leave empty for the default, {{ default_agent_url }}. Firewalls already enrolled keep the address they were enrolled with.

Usually leave this empty: firewalls connect straight to the agent port through a port forward. Only if they reach it through a TCP pass-through proxy or load balancer (HAProxy, nginx stream, Traefik TCP, a cloud load balancer…), have it send a PROXY protocol header (v1 or v2) and list its addresses below. ComSense then sees each firewall's real address, which it uses for per-address lockouts and shows as "checks in from". Connections that send a PROXY header from any other address are dropped, so the address cannot be faked. Leave empty when firewalls connect directly.
